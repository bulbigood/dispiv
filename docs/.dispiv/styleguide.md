## Эскалация блокеров

Если в процессе выполнения задачи ты обнаруживаешь любое из условий ниже —
НЕМЕДЛЕННО прекрати работу и создай файл по пути из поля `on_blocker.artifact`:

**Условия для создания blocker.md:**
- Файл из `allow_read` не существует или имеет неожиданную структуру
- Выполнение задачи требует изменить файл, которого нет в `allow_write`
- Обнаружен edge-case, не описанный в бизнес-инвариантах
- Компиляция после изменений невозможна без правки файлов вне sandbox

**Формат blocker.md:**
```yaml
task_id: <из YAML задачи>
reason: <одна фраза — суть проблемы>
discovered_in: <файл или метод, где обнаружен блокер>
required_action: <что нужно сделать человеку или AI_strong>
attempted: <что уже было попробовано>
```

После создания файла — не пытайся продолжить задачу. Останови выполнение.
